## Tatsu OS


**Tatsu OS** is a custom operating system built completely from scratch with a focus on understanding how computers work at the lowest level. Inspired by the Japanese word **立つ (Tatsu)**, meaning **"to stand"** or **"to rise,"** Tatsu OS represents an operating system that stands on its own through original design and implementation.

The project is written in **C** and **x86 Assembly**, beginning with a custom bootloader and evolving into a complete operating system. Every major component is being developed independently, including memory management, interrupt handling, device drivers, graphics, and system libraries.

### Current Features

* Custom boot process
* Framebuffer graphics rendering
* Terminal interface
* Physical and virtual memory management
* Paging support
* PS/2 keyboard driver
* PS/2 mouse driver
* Kernel heap foundation
* Higher-half kernel architecture
* Basic graphics primitives and rendering

### Planned Features

* Virtual File System (VFS)
* FAT file system support
* Window Manager
* Desktop Environment
* Custom GUI framework
* Multitasking and process scheduler
* ELF executable loader
* Dynamic memory allocator
* Networking stack
* Audio support
* Native applications such as Notepad, Calculator, File Explorer, and Terminal
* Software Development Kit (SDK) for creating native applications

### Vision

Tatsu OS is more than an operating system—it's a long-term educational and engineering project dedicated to learning kernel development, computer architecture, operating system design, and low-level programming. Every subsystem is designed with the goal of gaining a deep understanding of how modern operating systems function, while creating a clean, fast, and extensible platform for future development.

**Tatsu OS — Stand. Rise. Create.**
